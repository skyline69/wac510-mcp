# WAC510 MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a fast, type-safe FastMCP server that exposes the complete local management protocol of one NETGEAR WAC510.

**Architecture:** A persistent asynchronous protocol client owns authentication and transport. A capability catalogue merges common read selectors, while FastMCP tools add typed high-level operations, guarded raw access, and file transfer support.

**Tech Stack:** Python 3.14.7, uv, FastMCP 4.0.3, httpx 0.28.1, Pydantic 2, mypy 2.3.1, pytest 9.1.1, pytest-asyncio 1.4.0

**Spec:** `docs/superpowers/specs/2026-09-09-wac510-mcp-design.md`

## Global Constraints

- Target exactly one WAC510 per process.
- Read credentials only from `WAC510_*` environment variables.
- Keep credentials, cookies, security headers, and live payloads out of the repository.
- Use one persistent asynchronous connection pool.
- Preserve the firmware's JSON scalar types.
- Require confirmation for every mutation and exact tokens for disruptive operations.
- Run only read-only checks against the live AP.
